---
title: Keeping It Going
---

What happens to a Branch Sabbath School if initial enthusiasm wears off, if attendance drops, if interest wanes, or if all of these develop and discouragement sets in? Don’t give up. Take time to evaluate; then revise and keep moving.

- Change the location if necessary.
- Revise the program to be sure it is bright and lively; add music and other interest features.
- Re-establish visiting groups to visit those who have dropped.
- Consult with the pastor for support and encouragement.
- Pray for the direction of the Holy Spirit in this outreach endeavor.
